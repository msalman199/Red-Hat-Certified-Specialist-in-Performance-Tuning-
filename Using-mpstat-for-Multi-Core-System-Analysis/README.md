## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **mpstat** | Command-line tool for reporting CPU utilization, including per-core statistics |
| **Physical Cores vs. Logical Processors** | The actual CPU cores versus the processors the OS sees, which can be higher with hyperthreading |
| **Hyperthreading** | Technology that lets a single physical core present multiple logical processors |
| **Per-Core Utilization** | CPU usage measured on each individual core rather than as a single system-wide average |
| **Load Distribution / Load Balancing** | How evenly workloads are spread across available cores |
| **CPU Affinity** | Binding processes to specific cores to optimize performance |
| **Capacity Planning** | Using current usage patterns to make informed hardware-scaling decisions |
| **NUMA Optimization** | Advanced tuning technique tied to memory locality on multi-processor systems |
