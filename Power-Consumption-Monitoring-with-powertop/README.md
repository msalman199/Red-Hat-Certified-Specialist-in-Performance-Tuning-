## 🧠 Key Concepts

| 🔑 Concept | 📘 Description |
|-----------|----------------|
| **powertop** | 🔋 Tool for monitoring and analyzing power consumption |
| **CPU Governor** | 🧠 Policy controlling how CPU frequency scales with load |
| **Disk Power Management** | 💽 Settings that reduce disk power draw |
| **USB Autosuspend** | 🔌 Automatically suspending idle USB devices to save power |
| **Power Profile** | 🎛️ A saved set of settings for a usage scenario (performance, balanced, power save) |
| **Automated Power Management** | 🤖 Settings that switch automatically based on battery level and AC power status |
| **Power Consumption Report** | 📄 Generated output used for ongoing optimization |
