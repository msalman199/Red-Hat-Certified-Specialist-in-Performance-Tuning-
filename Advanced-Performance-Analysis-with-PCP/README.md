## 📖 Lab Overview

In this advanced lab, you installed and configured **Performance Co-Pilot (PCP)** across multiple systems, building a comprehensive monitoring infrastructure with distributed metric collection, real-time and historical analysis, automated alerting, visualization, and cross-system comparison.

> 🎓 **Certification Link:** Supports preparation for the **Red Hat Certified Specialist in Performance Tuning** exam.

---

## 🧪 Lab Environment

> 💡 **Lab Environment**
> Multiple Linux systems running **PCP**, used together to collect, log, analyze, and compare performance metrics across hosts.
